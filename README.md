I study psychology in Cologne and write software on the side, mostly for students, volunteering and my own self-hosted setup.

#### What I'm working on

- [Benemap](https://benemap.org) is a map of volunteering opportunities, starting with Cologne. The code is [here](https://github.com/oswaltx/BeneMap).
- [fachschaften.com](https://fachschaften.com) is a platform for student councils (Fachschaften). Its code is not public.
- [Moral-o-Mat](https://moral-o-mat.de) asks the 36 statements of the MFQ-2 questionnaire and gives you a values profile, also as a `moral.md` file for AI assistants. If you know a validated questionnaire that would fit, please [open an issue](https://github.com/oswaltx/moral-o-mat/issues/new/choose).
- [beneWave](https://github.com/oswaltx/benewave) (formerly greenWave Maps) is a CoMaps fork for cyclists. It suggests a speed so you reach the next traffic light while it is green. Still in beta.

#### Smaller tools

- [SuperProductivity Todo Sync](https://github.com/oswaltx/obsidian-superproductivity-todo-sync) shows your Super Productivity tasks in Obsidian.
- [Nuclivo](https://github.com/oswaltx/nuclivo) is a GTK app for the Proton Drive CLI on Linux.

I mostly write Kotlin, TypeScript and Python. Website: [oswalt.eu](https://oswalt.eu)
